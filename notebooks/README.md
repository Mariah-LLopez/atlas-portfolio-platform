# Research notebooks

Notebooks belong here only for exploration, charts, hypothesis development, and one-off diagnostics.

Once a calculation becomes part of the Atlas model, move it into `src/atlas` and test it.

Suggested first notebooks:

1. `01_market_data_exploration.ipynb`
2. `02_momentum_signal_research.ipynb`
3. `03_cma_research.ipynb`

The portfolio story is specifically **notebook → reviewed module → tests → CI → production run**.
